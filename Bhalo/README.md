# For Umamah ❤️

An ultra-modern, interactive romantic web application dedicated to Umamah celebrating 6 years of love and forever to go.

## Features
- **Interactive 3D Background**: Star constellation and floating 3D rose petals & hearts via Three.js.
- **Ambient Romantic Music**: Procedural acoustic lullaby / music box synthesizer via Web Audio API.
- **Dynamic Live Counter**: Real-time counter ticking every second of 6 years of devotion.
- **Heart-to-Heart Letter**: Parchment card with wax seal and heartfelt words.
- **3D Polaroid Scrapbook**: Memory timeline with high-resolution lightbox.
- **3D Tilt Nickname Cards**: Bhalo, Mera Bacha, Meri Pathani, Meri Zanani with secret thoughts.
- **Love Note Jar**: Tap to pop sweet love notes with floating emoji bursts.
- **Mood Lifter Widget**: Playful dodging button & celebration confetti unlocking eternal vows.
